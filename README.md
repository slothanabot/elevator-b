The joke: the elevator sounds helpful for half a second, then admits it has been stuck since Tuesday — and turns the complaint back on the passenger, who is just as stuck.

> Going up? Great. I've been stuck between floors since Tuesday — and frankly, so have you.

## Run it

```sh
python3 main.py
```
